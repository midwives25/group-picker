GROUP PICKER — PETUNJUK SINGKAT

1. Buka config.js.
2. Ganti PASTE_PROJECT_URL_DI_SINI dengan Project URL Supabase.
3. Ganti PASTE_PUBLISHABLE_KEY_DI_SINI dengan Publishable key Supabase (bukan Secret key).
4. Simpan semua file.
5. Upload isi folder ini ke repository GitHub.

Website membutuhkan tabel dan fungsi Supabase yang sudah dibuat pada langkah sebelumnya.
Jangan pernah menaruh Secret key atau service_role key di file frontend.
